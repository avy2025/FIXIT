FIXIT 🔧

FIXIT is a simple web-based project built using HTML, CSS, and JavaScript.
The idea behind this project is to design a basic service-booking style platform where users and admins can log in, explore services, and manage bookings through a clean UI and UX.

This project mainly focuses on frontend development, UI flow, and page navigation.

What is FIXIT about?

FIXIT simulates a service management system where:

Users can sign up and log in

Admins have separate login/signup pages

Services can be viewed and booked

A dashboard provides an overview of activities

It’s a beginner-friendly project created to practice real-world website structure and frontend logic.

Features

User Login & Signup pages

Admin Login & Signup pages

Dashboard interface

Service listing page

Booking page

Forgot password UI

Clean and simple design

JavaScript-based form handling and interactions

Note: This is a frontend-only project. Data is not stored permanently.

Tech Stack

The project is built using:

HTML – Page structure

CSS – Styling and layout

JavaScript – Basic interactivity and logic

No backend or database is used.

How to Run the Project

Clone the repository:

git clone https://github.com/avy2025/FIXIT.git


Open the project folder

Double-click index.html or open it in any browser

That’s it — no installation or server required.

How to Use

Start from index.html

Navigate through login/signup pages

Explore dashboard and service pages

Test basic form validations and UI flow

This project is best used as a learning project or portfolio demo.
